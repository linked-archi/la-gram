# Working on la-gram

Read [`.agents/conventions.md`](.agents/conventions.md) first: what la-gram is, its architecture
principles and code conventions, and the checklist for finishing a change — tests, the README, the
specifications in `.agents/specs/la-gram/` (requirements, design, and the change log in `tasks.md`), and
the documentation site in `docs-site/`.

| Path | Holds |
|---|---|
| `.agents/conventions.md` | principles, conventions, workflow, the checklist for finishing a change |
| `.agents/specs/` | the specifications ([index](.agents/README.md)) |
| `.agents/tasks/<name>/` | a piece of work someone else may continue: README, requirements, design, checklist |
| `docs-site/developing/documentation.md` | how the documentation site is written and built |

Kiro reads the same files through `.kiro/`, whose `specs` and `steering/project-conventions.md` are links
to them. Claude Code reads `CLAUDE.md`, which imports `.agents/conventions.md`.
