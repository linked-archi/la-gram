# Getting started

la-gram is the same app in the browser and on the desktop. Pick the one that suits you, then make a first
model.

| | In the browser | Desktop app |
|---|---|---|
| Install | nothing | unzip and open |
| Needs the network | to load the app; for metamodels that are not bundled; for Git | for metamodels that are not bundled; for Git |
| Files | opened from your computer and saved as downloads, or in Git | the same File menu |
| Git tokens remembered | only if you tick *Remember*, unencrypted in the browser | encrypted with the system keychain |
| Updates | every release, at the same address | download the next release |

1. [In the browser](web.md): open https://app.linked.archi/la-gram/, and the first URL parameters to try.
2. [Desktop app](desktop.md): download it, open it the first time, its menu bar.
3. [Your first model](first-model.md): a new model, elements placed and connected, validated and saved,
   step by step.

When you know your way round, the [User guide](../guide/index.md) goes through the workbench part by part.
